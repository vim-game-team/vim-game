## Requirements/Features 

## **MUST HAVES** 

- Allgemein 

   - Spielbarer Charakter 

   - Zentralisierte Map 

   - Beliebige Lvl Auswahl 

   - Möglichkeit zur Vertiefung 

   - Menu Punkt zu allen erlernten commands 

   - Storyline 

   - Log In / Spielspeicher 

- Level 

   - Command lern loop 

   - Gegner / Hindernisse 

   - Abschluss Rätsel 

- Challenge Rooms 

   - Leaderboards 

   - Timer 

## **NICE TO HAVES** 

- Multiplayer 

- Items 

- Replay für Leaderboard 

## User Stories 

## **Login / Registrierung** 

- **#1** – Als Spieler möchte ich mich registrieren können, damit ich ein Konto erstellen kann 

- **#2** –Als Spieler möchte ich mich einloggen können, damit ich meinen Fortschritt wiederfinde 

- **#2.1** – Als Spieler möchte ich mein Profil sehen können, damit ich meinen Fortschritt einsehen kann. 

- **#3** – Als Spieler möchte ich mich ausloggen können, damit meine Session sicher beendet wird 

## **Datenbank** 

- **#4** – Als Entwickler möchte ich eine DB-Struktur für User anlegen, damit Login/Registrierung funktioniert 

- **#5** – Als Entwickler möchte ich Spielfortschritt in der DB speichern, damit Level-Stände erhalten bleiben 

## **Einleitung** 

- **#6** – Als neuer Spieler möchte ich eine Einleitung sehen, damit ich verstehe wie das Spiel funktioniert 

- **#7** – Als Spieler möchte ich eine Übersicht aller Vim-Commands sehen, damit ich nachschlagen kann 

- **#7.1** – Als Spieler möchte ich das Tutorial überspringen können, damit ich schneller ins Spiel komme. 

## **Level-System** 

- **#8** – Als Spieler möchte ich ein erstes Level spielen können, damit ich Vim-Commands praktisch üben kann 

- **#8.1** – Als Spieler möchte ich mich durch verschiedene Level bewegen, damit ich Fortschritt im Spiel erlebe. 

- **#8.2** – Als Spieler möchte ich eine klare Zielvorgabe pro Level sehen, damit ich weiß, was ich erreichen muss. 

- **#9** – Als Spieler möchte ich einen Command-Loop pro Level haben, damit ich Commands wiederholt anwenden muss 

- **#10** – Als Spieler möchte ich ein Problem pro Level lösen, damit das Lernen spielerisch ist 

- **#11** – Als Spieler möchte ich nach Abschluss eines Levels das nächste freischalten, damit ich Fortschritt spüre 

## **Map** 

- **#12** – Als Spieler möchte ich eine 2D-Spielwelt sehen, damit ich meinen Charakter visuell bewegen kann 

- **#13** – Als Spieler möchte ich meinen Charakter mit h/j/k/l bewegen, damit ich die grundlegenden Vim-Bewegungen lerne 

- **#14** – Als Spieler möchte ich mit erweiterten Bewegungsbefehlen (w, b, gg, G) navigieren, damit ich komplexere Vim-Commands übe 

- **#15** – Als Spieler möchte ich Hindernisse/Ziele auf der Map haben, damit die Bewegungsbefehle einen Zweck im Spiel ergeben. 

- **#15.1** – Als Spieler möchte ich mit Objekten oder Elementen der Map interagieren können, damit ich Aufgaben lösen kann. 

- **#15.2** – Als Spieler möchte ich visuelles Feedback bei Bewegungen sehen, damit das Spiel lebendig wirkt. 

## **Challenge & Reward** 

- **#16** – Als Spieler möchte ich am Ende eines Levels eine Challenge haben, damit mein Wissen getestet wird 

- **#17** – Als Spieler möchte ich nach bestandener Challenge eine Belohnung erhalten, damit ich motiviert bleibe 

- **#17.1** – Als Spieler möchte ich Punkte sammeln können, damit mein Fortschritt sichtbar wird. 

- **#18** – Als Entwickler möchte ich ein Reward-System in der DB abbilden, damit Punkte/Badges gespeichert werden 

## **Charakter** 

- **#19** – Als Spieler möchte ich einen Charakter haben, damit ich mich mit einer Spielfigur identifizieren kann 

- **#20** – Als Spieler möchte ich meinen Charakter mit Rewards anpassen können, damit Fortschritt sichtbar wird
