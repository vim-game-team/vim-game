// COMMANDS

— BASIC MOVEMENT —

hMove left
jMove down
kMove up
lMove right

— WORD MOVEMENT —

wJump to start of next word (symbols count)
bJump back to start of word (symbols count)
BJump back to start of word (symbols ignored)
eJump to end of next word (symbols count)
EJump to end of next word (symbols ignored)

— MODE SWITCHING —

iInsert text before the cursor
